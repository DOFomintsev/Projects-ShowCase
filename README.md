# Projects-ShowCase

**[Открыть витрину проектов →](https://projects-showcase-denis.folksyluck4.chatgpt.site)**

Публичный архив витрины проектов Дениса Фоминцева. Веб-просмотр размещён отдельно от GitHub Pages, чтобы не затрагивать домен niceprice.pro.

- `index.html` — главная витрина с обложками проектов.
- `Витрина проектов/` — исходная витрина, видеопрезентации, ролики, обложки и офлайн-пакеты.

Исходники и материалы доступны в этом GitHub-репозитории.
